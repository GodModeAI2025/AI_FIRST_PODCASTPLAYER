# ADR 0011 — Feed-Erkennung und historische Kataloge trennen
Status: Entwurfsentscheidung, 19.09.2026.
Ein normaler YouTube-Link wird auf stabile Kanalidentität aufgelöst und als Vorschau mit Abo/Einzelimport/Archivaktionen dargestellt. Atom ist Updateschnittstelle; offizielle Uploads-Pagination erschließt den verfügbaren historischen Katalog. Inhaltsanalyse benötigt separat zulässigen Audio-/Textzugang. Vollständigkeit ist katalog- und analysebezogen getrennt. [Y01–Y06]
