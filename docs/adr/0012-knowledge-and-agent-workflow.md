# ADR 0012 — Wissensobjekte und externe Weitergabe
Status: Entwurfsentscheidung, 19.09.2026.
Highlights und Transkripte sind portable Objekte. Native semantische Suche umfasst ungehörte analysierte Folgen. Optionaler Swift-MCP-Helfer auf Mac gibt nur freigegebene Daten und vorbereitete Vorschläge aus. Er erweitert die appinterne Apple-only-Modellwahl nicht. Native Suche/Translation und aktueller request-scoped MCP-Stand werden separat geprüft. [A10, A25, M01–M03]
